REGRAS FIRESTORE - IMPORTACAO E PRODUCAO

1) REGRA TEMPORARIA (somente para importar)
Use apenas durante migracao/importacao. Depois remova.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

2) IMPORTAR DADOS
Depois de publicar a regra temporaria, execute:
- .\import_firestore.ps1

3) REGRA FINAL RECOMENDADA (PRODUCAO)
Use esta regra com Firebase Authentication habilitado.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isSignedIn() {
      return request.auth != null;
    }

    // Contratos do dashboard
    match /contratos/{docId} {
      allow read, write: if isSignedIn();
    }

    // Listas auxiliares: areas, acoes, advs, tipos, origens, meses e fotos
    match /meta/{docId} {
      allow read, write: if isSignedIn();
    }

    // Bloqueia qualquer outra rota nao usada pelo app
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

Observacoes:
- Esta regra exige login para todo acesso de app.
- Se quiser restringir por perfil (somente admin editar), o proximo passo e usar custom claims.
