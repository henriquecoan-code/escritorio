CONFIGURACAO FIREBASE - DASHBOARD

1) Criar projeto no Firebase
- Acesse console.firebase.google.com
- Crie um projeto
- Ative Cloud Firestore (modo producao ou teste temporario)

2) Criar app Web
- Em Configuracoes do projeto > Seus apps > Web
- Copie o objeto de configuracao Firebase

3) Preencher arquivo local
- Abra firebase-config.js
- Substitua window.OB_FIREBASE_CONFIG = null; pelo objeto real

4) Estrutura usada no Firestore
- Colecao: contratos (docId = uid)
- Colecao: meta, documento: lists
- Colecao: meta, documento: photos

5) Comportamento da aplicacao
- Se firebase-config.js tiver configuracao valida, o sistema usa Firebase automaticamente
- Se nao tiver, continua usando servidor local/offline atual

6) Regras iniciais (sugestao simples para inicio)
- Em producao, nao deixe regras abertas
- Comece com autenticacao e regras por usuario/equipe

7) Migracao inicial
- Na primeira carga com Firebase vazio, o sistema publica automaticamente o SEED_DATA
- Depois disso, os novos salvamentos/edicoes/exclusoes vao para Firestore

8) Regras temporarias sem autenticacao (fase atual)
- Se voce ainda nao vai usar Firebase Auth, as Rules precisam permitir acesso sem login.
- Exemplo temporario:

rules_version = '2';
service cloud.firestore {
	match /databases/{database}/documents {
		match /contratos/{docId} {
			allow read, write: if true;
		}
		match /meta/{docId} {
			allow read, write: if true;
		}
		match /{document=**} {
			allow read, write: if false;
		}
	}
}

9) Pendencia registrada
- Implementar Firebase Auth e endurecer Rules (request.auth != null) na proxima fase.

10) Authentication (implementado)
- No Firebase Console: Build > Authentication > Sign-in method > habilitar Email/Password.
- Criar pelo menos um usuario em Authentication > Users.
- O dashboard agora exige login para ler/escrever dados no Firestore.
- Se o usuario nao estiver autenticado, a tela de login e exibida automaticamente.

Observacao
- Esta etapa integra Firestore no frontend.
- Recomendacao atual: manter Rules com request.auth != null para contratos e meta.
